# 仙台の新音楽ホールを考えるためのデータ集

音楽堂ホールを考える会（執筆：畠山紳悟）の note 連載「仙台の新音楽ホールのお金を読む」（全4回）で使ったデータです。

## 使い方
- 利用条件：CC BY 4.0。出典として「音楽堂ホールを考える会『仙台の新音楽ホールを考えるためのデータ集』」と書けば、転載・加工・再配布は自由です。
- 文字コード：UTF-8（BOM付き）。Excelでそのまま開けます。
- 金額は、ファイルごとに「円」か「億円」かを列名に書いています。
- 「区分」の列の意味
  - 事実：公開資料にそのまま書かれている数字
  - 試算：公開資料をもとに会が計算した数字。計算方法や仮定は同じ行か、記事の「計算の仮定」に書いてあります
  - 事実（会の集計）：公開情報を会が数え上げたもの

## 注意
- 他都市のホールの使用料の多くは、仙台市の資料にある推定値です。年度や稼働率の数え方は施設ごとに違います。
- 11の感度分析は、市の資料の「335日」を開館日数として計算しています（使用日数＝335日×稼働率）。
- 14の民間支援は日本オーケストラ連盟の集計の定義によります。仙台フィルの決算書の「寄付金」とは範囲が異なります。
- 間違いを見つけたら、noteのコメントで教えてください。直したら、日付と理由をこのファイルに記録します。
